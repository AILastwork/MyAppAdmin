OSNOVA · инструкция администратора

Первый запуск MyAppAdmin

Пошаговая подготовка нового Windows-хоста: от запуска EXE до безопасной проверки AD, Yandex 360, 1C и принтеров.

Версия 0.16.7 Windows x64 Python не требуется Работа в домене OSNOVA

Что должно быть рядом

Для обычного запуска достаточно EXE. Остальные файлы помогают настроить и проверить приложение.

MyAppAdmin.exe

Готовое приложение. Все Python-библиотеки уже находятся внутри.

MyAppAdmin_First_Run.html

Эта инструкция. Работает локально и не требует интернета.

printers.json

Общий список МФУ. По умолчанию приложение ищет его в общей папке MyAppAdmin.

Не запускайте EXE прямо из ZIP-архива. Сначала распакуйте комплект в локальную папку, например C:\MyAppAdmin.

Порядок первого запуска

Выполните шаги по порядку. Это быстрее, чем возвращаться к настройкам после первой ошибки.

1

Запустите EXE

Откройте MyAppAdmin.exe под своей доменной учетной записью. Повышение до локального администратора Windows обычно не требуется.

2

Разрешите доверенный файл

Если SmartScreen показывает предупреждение, убедитесь, что файл получен из доверенного внутреннего источника, затем выберите «Подробнее» и «Выполнить в любом случае».

3

Проверьте версию

В заголовке окна и разделе «Описание программы → Версии» должна быть указана версия 0.16.7 или новее.

4

Откройте настройки

Раздел виден только текущему Windows-пользователю из Domain Admins. При первом запуске настройку выполняет доменный администратор.

5

Проверьте подключения

Заполните LDAPS-сервер, учетную запись чтения AD и секреты. Проверьте пути Yandex, принтеров, шаблонов 1C и базовый URL GLPI.

6

Откройте главную

Карточки общих файлов должны показывать доступность. Недоступный путь сначала проверяется в Проводнике под текущим Windows-пользователем.

Общая папка по умолчанию

Приложение использует корень:

\\osnova.local\fs\IT\MyAppAdmin

НазначениеПуть по умолчанию
Шаблоны 1C\\osnova.local\fs\IT\MyAppAdmin
Yandex token-файл\\osnova.local\fs\IT\MyAppAdmin\API_yandex360.txt
Список принтеров\\osnova.local\fs\IT\MyAppAdmin\printers.json
Пути можно изменить в настройках. Секреты из настроек сохраняются локально через Windows DPAPI и не должны переноситься копированием чужого config.json.
При запуске EXE показывает анимированную сетевую заставку со сканирующим лучом, сетевыми искрами, glow-слоями и бегущими сигналами. Служебные проверки Windows запускаются скрыто, поэтому черные консольные окна появляться не должны.

Первая безопасная проверка

  • В разделе «Поиск AD» найдите тестового пользователя и убедитесь, что чтение каталога работает.
  • В «Почта Yandex» загрузите одну организацию и сохраните выборку кнопкой «Сохранить в Excel».
  • В «Принтеры» сначала используйте предпросмотр и проверенный тестовый МФУ.
  • Создание AD-пользователя сначала выполните в тестовой OU и без файловых операций.
  • Проверьте, что административные группы отсутствуют в выбранных группах.
Создаваемого сотрудника нельзя включить в административную группу. Приложение блокирует такие группы по имени, SID/RID, adminCount=1 и вложенному членству. Если старая сборка показывает успешное включение в «Администраторы» или «Администраторы домена», немедленно прекратите её использование и запустите актуальную версию.

Где хранится локальная конфигурация

При первом запуске создаются:

Настройки%APPDATA%\MyAppAdmin\config.json
Журнал аудита%APPDATA%\MyAppAdmin\audit.db
Локальные принтеры%APPDATA%\MyAppAdmin\printers.local.json

Пароли AD-read, Kyocera и SMB в JSON выглядят как dpapi:v1:.... Это нормально: значение зашифровано для Windows-профиля, в котором оно было сохранено.
